# 🚀 AskAnySite AI

An AI-powered web application that allows users to interact with any website using a chatbot interface.

## 📌 Features
- Chat with any website
- AI-powered responses
- Website content extraction
- Clean UI

## ⚙️ Tech Stack
- Frontend: Next.js + Tailwind
- Backend: FastAPI
- AI: Gemini API

## 🚀 How to Run

### Frontend
cd frontend  
npm install  
npm run dev  

### Backend
cd backend  
pip install -r requirements.txt  
python -m uvicorn main:app --reload  

## 💡 Approach
We use scraping + embeddings + AI to answer questions based on website content.
